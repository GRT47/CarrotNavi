# CarrotNavi 업데이트 릴리즈 노트

---

## 1. 내비 앱 (NaviApp)

### v2.1.1
* **오픈파일럿 구간단속 인식 오류 패치**
  - TMAP 및 카카오내비 모드에서 구간단속 진입 후 오픈파일럿이 단속 속도를 잃어버리고 락이 풀리는 현상 해결.
  - 기존에 앱 설정의 '구간단속 속도 상향(오프셋/펀치력)' 값이 0일 때, 오픈파일럿이 구간단속을 인식하는 데 필요한 필수 파라미터(`nSdiBlockSpeed`) 데이터가 통째로 누락되어 전송되던 구조적 버그 해결.
  - 펀치력 설정 여부와 상관없이 무조건 원래의 제한속도 값을 복사해 전송하도록 안전 장치를 추가하여 순정 상태에서도 정상 작동하도록 개선.

### v2.1.0
* **관제 서버 통신 최적화 및 설정 단순화**
  - 리버스 프록시(HTTPS) 환경 지원을 위해 관제 서버 URL(`https://comma-nav-server.leegrt.org`)을 앱 내부에 하드코딩하여 통신 안정성 확보.
  - 앱 내 원격 설정 페이지(8080 포트)에서 불필요해진 '관제 서버 URL' 입력란을 제거하여 사용자 편의성 증대 및 오작동 방지.

### v2.0.10
* **앱 완전 종료 시 백그라운드 좀비 프로세스 현상 수정**
  - '앱 완전 종료' 버튼 클릭 시 UDP 통신 및 웹 서버 서비스가 명시적으로 종료되도록 수정하여, 앱 종료 후에도 시스템에 의해 강제 재실행되는 버그 해결.
* **지도 화면 HUD 버튼 레이아웃 최적화**
  - 우측 하단의 4개 버튼을 기존 2x2 형태에서 세로 1열 4행(설정, 주소 검색, 편집, 숨김) 배열로 변경하여 지도 시야 개선 및 직관성 향상.
* **목적지 검색 화면 잘림 현상 개선**
  - 검색창 및 결과 리스트가 기기의 시스템 영역(상단 상태 바, 하단 내비게이션 바)을 침범하여 가려지는 UI 오류 수정.
* **상세 설정 팝업 내 기기 IP 주소 표출**
  - 원격 접속 편의를 위해 상세 설정 팝업 최하단에 현재 동작 중인 기기의 내부 IP 주소와 mDNS 주소를 표시하도록 기능 추가.

### v2.0.9
* **카카오내비 구간단속 오픈파일럿 연동 지원**
  - 카카오내비 사용 시 구간단속 이벤트(`KNSafetyType_Section`)를 정상적으로 인식하여, TMAP과 동일하게 구간단속 평균/제한 속도 데이터를 오픈파일럿으로 송신하도록 구현.
* **오픈파일럿 통신 데이터 파이프라인 안정화**
  - 1차 단속 제한 속도(`nSdiSpeedLimit`)가 0으로 내려올 경우, 구간단속 제한속도(`nSdiBlockSpeed`) 값을 차용하도록 예외 처리 추가.

### v2.0.8
* **오픈파일럿 최신 버전 호환성 패치**
  - 최신 오픈파일럿(`carrot-wip` 브랜치) 환경에서 구간단속 중간 지점 통과 시 단속 정보를 인식하지 못하고 락이 풀리는 문제 수정 (`nSdiSpeedLimit` 폴백 로직 추가).
* **미디어 아티스트명 표출 오류 수정**
  - FLO 등 특정 음악 플레이어 앱 사용 시, 아티스트 정보가 누락되어 UI에 표시되지 않던 버그 수정 (빈 문자열 처리 개선).

### v2.0.5
* **내비게이션 안내 음성 볼륨 조절 기능 추가**
  - 기존에 음소거 처리되어 있던 길 안내 음성을 사용자가 직접 조절할 수 있도록 변경.
* **안내 중 배경 음악 자동 조절 기능 적용**
  - 길 안내 음성 송출 시, 재생 중인 미디어(음악 등) 음량을 자동으로 감소시키거나 일시 정지하는 기능 추가.
* **화면 자동 꺼짐 방지 개선**
  - 내비게이션 실행 중 화면이 어두워지거나 꺼지는 증상 해결.
* **NavClient앱 연결 안정성 개선**
  - 자체 IP 변경 감지 모니터 추가(1초 주기). 네트워크 환경 변경 시 기기 간 연결 서비스 자동 재등록.

## 2. 클라이언트 앱 (ClientApp)

## 3. 관제 서버 (ServerApp)

### 최신 업데이트 사항
* **실시간 로그 수집 및 모니터링 기능 신규 구축**
  - 내비앱의 동작 상태(로그)를 실시간으로 수집하고, 웹 대시보드에서 기기별로 간편하게 조회할 수 있는 통합 관제 시스템 추가.
* **대시보드 브랜딩 및 편의 기능 대폭 강화**
  - 프로젝트 명칭 변경에 맞춰 대시보드 타이틀을 **CommaNav 관제 서버**로 일괄 통일.
  - 기기 목록에 **온라인 / 오프라인** 상태 표시 뱃지를 추가하여 실시간 접속 여부 직관적 확인 가능.
  - 복잡한 16자리 기기 ID 대신 사용자가 원하는 이름으로 변경해 볼 수 있는 **기기 별명(Alias)** 편집 기능 추가.
* **유지보수 및 배포 환경 최적화**
  - 무한정 쌓이는 로그를 방지하기 위해 **7일 경과 로그 자동 삭제(Log Rotation)** 정책 적용.
  - Docker Hub에 공식 이미지(`grt47/comma_nav_server:latest`)를 퍼블리시하고 `docker-compose.yml`을 개선하여 Portainer에서 1초 만에 서버를 구축할 수 있도록 지원.
  - 템플릿 파일 핫-리로딩(`TEMPLATES_AUTO_RELOAD = True`) 적용 및 데이터(`data/`) 영구 보존 볼륨 마운트 구조 도입.
