# CarrotNavi 업데이트 릴리즈 노트

---

## 1. 내비 앱 (NaviApp)

### v2.1.8

* **도로 기본 제한속도 표시 및 단속 카메라 동적 연동**
  * 단속 이벤트가 없을 때는 도로의 제한속도 표지가 나오고, 단속 이벤트가 있을 때는 단속 이벤트만 나오도록 전환 처리.
  * **카카오내비 주행 시 동적 위치 보정**: 경로안내 중 좌측 탭 생성 및 속도계/카메라 표지판 위치 변화에 맞춰 도로 제한속도 위젯 위치를 실시간으로 자동 보정.
* **하단 주행종료 버튼 오터치 방지 및 GPS 상태 바 개편**
  * **하단 바 일체형 GPS 오버레이**: 티맵 및 카카오내비 하단 영역(주행종료 버튼 위치) 크기·위치에 완벽히 일치하는 일체형 GPS 바로 덮어 주행 중 실수로 인한 주행종료 터치를 원천 방지.
  * **현재 위치 실시간 주소 표출**: GPS 오버레이 바 내에 현재 주행 중인 도로명 및 지번 주소를 실시간으로 표시.
* **경로안내 모드 HUD 오버레이 인터랙션 및 레이아웃 대폭 개선**
  * **TBT 회전 안내 패널 동적 연동**: 경로안내 시작 시 [집, 사무실, 즐겨찾기] 캡슐 버튼이 KNSDK TBT 회전 안내 패널과 연동 (가로 화면: TBT 패널 우측 옆, 세로 화면: TBT 패널 아래 우측 배치).
  * **GPS 오버레이 도착 정보 및 경로취소 기능 추가**: 하단 GPS 바에 목적지 도착 예정 시간 및 남은 거리 정보 표시 (도착시간 터치 시 남은 시간/도착예정시간 토글 전환), 맨 우측에 원터치 경로 취소(TMAP 안전운행 복귀) 버튼 추가.
  * **목적지 미리보기 화면 최적화**: 5초 대기 미리보기 화면에서 GPS 오버레이를 숨겨 경로선 및 지도 가림 방지.
  * **경로안내 중 검색 버튼 유지**: 경로안내 모드 진입 후에도 주소 검색 버튼이 유지되어 주행 중 언제든 재탐색 가능.
* **HUD 조작성 정리 및 버튼 간소화**
  * 불필요한 오버레이 편집/접기토글 버튼을 제거하고, 우측 하단에 단독 주소 검색 버튼 배치.
  * "OP 연결 대기" 오버레이를 주행화면 우측 상단 모서리로 고정.
* **미디어 화면 분할 경계선 핸들(Split Handle) 터치 드래그 & 토글 지원**
  * **경계선 직접 드래그 조절**: 지도와 미디어 화면 경계선에 배치된 알약형 핸들을 드래그하여 주행 중 설정창 없이 실시간으로 분할 비율 조절 가능 (0.5 단위 및 주요 비율로 부드럽게 스냅).
  * **원터치 탭 전체화면 토글**: 핸들을 가볍게 탭하면 미디어가 닫히며 지도가 전체화면으로 확장되고, 다시 탭하면 이전 사용 비율로 즉시 복원.
  * **닫힘 상태 복원 편의성**: 미디어가 닫힌 전체화면 상태에서도 화면 가장자리에 얇은 핸들이 유지되어 언제든 쉽게 다시 열기 지원.
  * **앨범아트 터치 시 미디어 분할 설정 메뉴 호출**: 미디어 플레이어의 앨범아트(카드)를 터치하면 화면 분할 비율(1:1, 7:3, 4:1, 전체화면 퀵 프리셋 및 슬라이더)과 배경 스타일(앨범아트/EQ 시각화)을 즉시 설정할 수 있는 전용 모달 메뉴 표출.
* **설정 버튼 상단 미디어 재생현황 플로팅 오버레이 추가**
  * **미디어 오버레이 원터치 버튼**: 우측 하단 설정 버튼 상단에 음표 모양의 미디어 토글 버튼 배치.
  * **플로팅 미디어 카드 (재생현황 특화)**: 불필요한 컨트롤 버튼을 과감히 제거하고 재생현황(앨범아트, 곡 제목, 아티스트, 실시간 재생/일시정지 상태 뱃지)에 집중하여 더욱 슬림하고 미려한 디자인 적용.
  * **미디어 오버레이 자유 드래그 이동 & 위치 저장**: 플로팅 카드를 원하는 위치로 화면 어디든 드래그하여 이동 가능하며, 가로/세로 모드별 위치 자동 기억 및 복원.
  * **위치 초기화 지원**: 음표 버튼을 길게 누르면 미디어 카드가 원래 기본 위치로 즉시 복원.
  * **미디어 오버레이 활성화 시 분할모드 비활성화 및 주행화면 전체화면 자동 전환**: 미디어 플로팅 카드가 켜져 있는 동안에는 미디어 분할모드가 비활성화되어 주행화면이 전체화면으로 넓게 표출되고 분할 경계선 핸들도 함께 숨김 처리되며, 미디어 오버레이를 닫으면 원래 설정된 분할 화면 비율과 핸들이 복원.
  * **미디어 오버레이 앨범아트 터치 시 가로/세로 형태 선택 메뉴 제공**: 미디어 플로팅 카드의 앨범아트를 탭하면 '가로 형태 (수평 바)'와 '세로 형태 (콤팩트 카드)'를 선택할 수 있는 팝업 메뉴가 표출되어 취향 및 차량 거치 환경에 맞게 원하는 형태로 즉시 전환 가능.
  * **오버레이 하단 테두리 실시간 재생 진행바(Progress Bar) 구현**: 오버레이 카드 하단 테두리를 따라 부드럽게 흐르는 슬림(3dp) 실시간 재생 진행바를 추가하여, 별도의 컨트롤 영역 없이도 현재 곡의 재생 진행률과 남은 분량을 한눈에 직관적으로 확인 가능 (미디어 팝업 플레이어와 동일한 세련된 블루 그라데이션 컬러 적용).
  * **세로 형태 카드 레이아웃 및 텍스트 여백 최적화**: 카드 높이를 188dp로 확장하고 하단 패딩 및 폰트 여백을 보정하여, 세로 형태에서도 아티스트명이 잘림 없이 온전하고 선명하게 표출되도록 개선.
  * **곡명 및 아티스트명 긴 텍스트 자동 마퀴(Marquee) 스크롤 지원**: 곡 제목이나 가수 이름이 오버레이 카드 폭보다 길어질 경우 말줄임표 대신 자동으로 부드럽게 흐르는 텍스트 애니메이션(Marquee)을 적용하여 전체 텍스트를 편리하게 확인 가능.
  * **원터치 미디어 분할 설정 연동**: 플로팅 카드의 앨범아트 외 영역(곡 정보 등)을 가볍게 탭하면 미디어 화면 분할 및 배경 스타일 설정 창으로 즉시 이동.

### v2.1.7

* **목적지 검색 결과 자동 경로안내 시작 오류 수정**
  * 검색어 입력 후 검색 시 결과 목록이 표시되지 않고 첫 번째 검색 결과로 자동 경로 안내가 즉시 시작되던 버그 수정.
  * 검색 결과 목록을 사용자가 직접 확인하고 원하는 목적지를 터치했을 때만 경로 안내가 시작되도록 터치 이벤트 격리.

### v2.1.6

* **주행화면 좌측 상단 1행 바로가기 버튼(집, 사무실, 즐겨찾기) 추가**
  * 주행화면 좌측 상단에 1행으로 가로 정렬된 반투명 다크 캡슐형 버튼(`[🏠 집]`, `[🏢 사무실]`, `[⭐ 즐겨찾기]`) 제공.
  * 원터치로 등록된 목적지 즉시 안내 시작 및 롱클릭 시 변경/삭제 관리 메뉴 지원.
  * 미등록 상태에서 터치 시 검색 화면으로 자연스럽게 안내 및 자동 등록 지원.
* **목적지 검색 결과 및 최근 검색 기록에서의 원터치 등록 지원**
  * 검색 상세 프리뷰 카드 및 검색 결과/최근 기록 리스트에서 바로 `[🏠 집으로 등록]`, `[🏢 사무실로 등록]`, `[⭐ 즐겨찾기에 추가]` 가능.
* **즐겨찾기 전체화면(Full-Screen) 통합 목적지 허브 개편**
  * 즐겨찾기 버튼 터치 시 좁은 하단 시트 대신 전체화면 다이얼로그로 시원하게 전환.
  * 상단에 집/사무실 바로가기 카드 배치, 하단에 즐겨찾기 카드 그리드/리스트(가로 2열, 세로 1열) 배치.
  * 카드 터치 또는 `[🚀 안내]` 버튼을 통한 즉시 길안내 시작 및 개별 삭제 지원.
* **목적지 검색 화면 지도 프리뷰 및 조작성 개선**
  * 지도 패널을 크게 확대하고 버튼/정보 카드를 지도 위 오버레이 형태로 재배치.
  * 지도 스크롤/확대/축소 시 목적지 핀 마커 중앙 고정 UX 적용.
  * 검색 화면 테마를 보라색에서 세련된 딥 차콜/슬레이트 블루 모던 테마로 개선.

### v2.1.3

### v2.1.21

* **구간단속 카메라 데이터 전송 구조 (이중 구조) 버그 수정**
  * 경로 안내(카카오내비) 모드 주행 중, 구간단속 시작 지점을 통과한 이후부터 앱이 구간단속 중임을 인지하지 못하고 단속 상태가 조기 해제되는 치명적 오류 수정.
  * 카카오내비 SDK의 단속 카메라 데이터 생략(제한적 제공) 문제를 우회하기 위해, 경로 안내 중에도 단속 카메라 및 속도(SDI) 정보는 항상 백그라운드의 TMAP 데이터만을 추출하여 오픈파일럿으로 전송하도록 `UdpSenderService` 데이터 병합 로직 수정.
  * 이를 통해 카카오 화면을 보면서도 TMAP 수준의 정밀도 높은 구간단속 정보를 오픈파일럿이 활용할 수 있게 되어, 진정한 "하이브리드 모드" 완성.

### v2.1.2

  * 재생 바와 컨트롤 버튼을 '차가운 계열(블루/시안)' 그라데이션과 알약(Pill) 형태로 변경하여 세련되고 현대적인 디자인 적용.
  * 가로 화면과 세로 화면 각각의 미디어 창 분할 비율을 독립적으로 저장하고 기억하도록 개선 (UX 편의성 향상).
  * 다음/이전 곡 변경 시 앨범 커버 애니메이션(페이드/스케일) 효과 추가.
  * 세로 화면에서 앨범 커버를 좌측, 노래 정보(제목, 가수, 시간)를 우측에 배치하여 공간 활용 최적화.

  * 경로 안내 도중 앱 강제 종료 또는 기기 재부팅 발생 시, 1시간 이내 앱 재실행 시 "최근 목적지 안내 복구" 팝업창 제공.
  * 팝업창 위치를 초기 설정 화면(MainActivity)이 아닌 TMAP 기본 지도 화면(MapActivity) 위로 띄워 자연스러운 사용자 경험(UX) 제공.
  * 5초 카운트다운 타이머를 적용하여 방치 시 자동으로 복구 '확인' 버튼이 눌리도록 편의 기능 추가.

### v2.1.1

* **오픈파일럿 구간단속 인식 오류 패치**
  * TMAP 및 카카오내비 모드에서 구간단속 진입 후 오픈파일럿이 단속 속도를 잃어버리고 락이 풀리는 현상 해결.
  * 기존에 앱 설정의 '구간단속 속도 상향(오프셋/펀치력)' 값이 0일 때, 오픈파일럿이 구간단속을 인식하는 데 필요한 필수 파라미터(`nSdiBlockSpeed`) 데이터가 통째로 누락되어 전송되던 구조적 버그 해결.
  * 펀치력 설정 여부와 상관없이 무조건 원래의 제한속도 값을 복사해 전송하도록 안전 장치를 추가하여 순정 상태에서도 정상 작동하도록 개선.

### v2.1.0

* **관제 서버 통신 최적화 및 설정 단순화**
  * 리버스 프록시(HTTPS) 환경 지원을 위해 관제 서버 URL(`https://comma-nav-server.leegrt.org`)을 앱 내부에 하드코딩하여 통신 안정성 확보.
  * 앱 내 원격 설정 페이지(8080 포트)에서 불필요해진 '관제 서버 URL' 입력란을 제거하여 사용자 편의성 증대 및 오작동 방지.

### v2.0.10

* **앱 완전 종료 시 백그라운드 좀비 프로세스 현상 수정**
  * '앱 완전 종료' 버튼 클릭 시 UDP 통신 및 웹 서버 서비스가 명시적으로 종료되도록 수정하여, 앱 종료 후에도 시스템에 의해 강제 재실행되는 버그 해결.
* **지도 화면 HUD 버튼 레이아웃 최적화**
  * 우측 하단의 4개 버튼을 기존 2x2 형태에서 세로 1열 4행(설정, 주소 검색, 편집, 숨김) 배열로 변경하여 지도 시야 개선 및 직관성 향상.
* **목적지 검색 화면 잘림 현상 개선**
  * 검색창 및 결과 리스트가 기기의 시스템 영역(상단 상태 바, 하단 내비게이션 바)을 침범하여 가려지는 UI 오류 수정.
* **상세 설정 팝업 내 기기 IP 주소 표출**
  * 원격 접속 편의를 위해 상세 설정 팝업 최하단에 현재 동작 중인 기기의 내부 IP 주소와 mDNS 주소를 표시하도록 기능 추가.

### v2.0.9

* **카카오내비 구간단속 오픈파일럿 연동 지원**
  * 카카오내비 사용 시 구간단속 이벤트(`KNSafetyType_Section`)를 정상적으로 인식하여, TMAP과 동일하게 구간단속 평균/제한 속도 데이터를 오픈파일럿으로 송신하도록 구현.
* **오픈파일럿 통신 데이터 파이프라인 안정화**
  * 1차 단속 제한 속도(`nSdiSpeedLimit`)가 0으로 내려올 경우, 구간단속 제한속도(`nSdiBlockSpeed`) 값을 차용하도록 예외 처리 추가.

### v2.0.8

* **오픈파일럿 최신 버전 호환성 패치**
  * 최신 오픈파일럿(`carrot-wip` 브랜치) 환경에서 구간단속 중간 지점 통과 시 단속 정보를 인식하지 못하고 락이 풀리는 문제 수정 (`nSdiSpeedLimit` 폴백 로직 추가).
* **미디어 아티스트명 표출 오류 수정**
  * FLO 등 특정 음악 플레이어 앱 사용 시, 아티스트 정보가 누락되어 UI에 표시되지 않던 버그 수정 (빈 문자열 처리 개선).

### v2.0.5

* **내비게이션 안내 음성 볼륨 조절 기능 추가**
  * 기존에 음소거 처리되어 있던 길 안내 음성을 사용자가 직접 조절할 수 있도록 변경.

* **화면 자동 꺼짐 방지 개선**

## 3. 관제 서버 (ServerApp)

### 최신 업데이트 사항

* **실시간 로그 수집 및 모니터링 기능 신규 구축**
  * 내비앱의 동작 상태(로그)를 실시간으로 수집하고, 웹 대시보드에서 기기별로 간편하게 조회할 수 있는 통합 관제 시스템 추가.
* **대시보드 브랜딩 및 편의 기능 대폭 강화**
  * 프로젝트 명칭 변경에 맞춰 대시보드 타이틀을 **CommaNav 관제 서버**로 일괄 통일.
  * 기기 목록에 **온라인 / 오프라인** 상태 표시 뱃지를 추가하여 실시간 접속 여부 직관적 확인 가능.
  * 복잡한 16자리 기기 ID 대신 사용자가 원하는 이름으로 변경해 볼 수 있는 **기기 별명(Alias)** 편집 기능 추가.
* **유지보수 및 배포 환경 최적화**
  * 무한정 쌓이는 로그를 방지하기 위해 **7일 경과 로그 자동 삭제(Log Rotation)** 정책 적용.
  * Docker Hub에 공식 이미지(`grt47/comma_nav_server:latest`)를 퍼블리시하고 `docker-compose.yml`을 개선하여 Portainer에서 1초 만에 서버를 구축할 수 있도록 지원.
  * 템플릿 파일 핫-리로딩(`TEMPLATES_AUTO_RELOAD = True`) 적용 및 데이터(`data/`) 영구 보존 볼륨 마운트 구조 도입.
