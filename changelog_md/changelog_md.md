# CarrotNavi 업데이트 릴리즈 노트

---

## 1. 내비 앱 (NaviApp)

### v2.2.2

* **초기 설정 화면 내 네트워크 통신 및 API 키(Tmap / Kakao) 실시간 연결 진단 테스트 기능 구현**
  * **올인원 진단 테스트 카드(`MaterialCardView`) 도입**:
    * 앱 초기 설정 화면(`MainActivity`)의 Kakao API 설정 하단에 모던 다크 테마 기반의 **"연결 및 API 키 진단 테스트"** 전용 카드를 배치.
    * 사용자가 입력한 API 키가 유효한지, 차량/기기의 인터넷 연결이 정상적으로 외부망과 통신하는지 진입 즉시 한 번의 터치로 원클릭 점검 가능.
  * **4단계 핵심 통신 파이프라인 실시간 검증 및 시각적 상태 배지 표출**:
    1. **🌐 인터넷 네트워크**: `NetworkUtil.isNetworkAvailable` 검사, 전송 인터페이스 판별(Wi-Fi, LTE/5G, 이더넷, USB 테더링, VPN), 기기 로컬 IP 확인 및 외부망 HTTP 왕복 지연 시간(RTT ms) 실시간 측정.
    2. **🗺️ Tmap SDK (안전운행)**: 입력된 Tmap App Key를 기반으로 SK 라이선스 서버 인증을 직접 수행하여 안전운행 SDK 사용 가능 여부 판정.
    3. **🚗 Kakao 내비 SDK (경로안내)**: `KNSDK.install` 컨텍스트 설정 및 `KNSDK.initializeWithAppKey`를 호출하여 카카오 모빌리티 라이선스 서버 인증 성공 여부 및 에러 코드 정밀 진단.
    4. **🔍 Kakao REST API (목적지 검색)**: Kakao Local Keyword Search API(`https://dapi.kakao.com/v2/local/search/keyword.json`)로 '서울역' 테스트 검색을 즉시 요청하여 REST API 키의 유효성 및 HTTP 응답 코드(200 성공, 401/403 인증 실패 등)를 직관적으로 표출.
  * **인체공학적 UX 및 오토 스크롤링 지원**:
    * 테스트 시작 시 진행 바(`ProgressBar`) 표시 및 현재 입력된 키 값을 SharedPreferences에 자동 동기화/저장.
    * 결과 패널 노출 시 화면이 아래로 자동 스크롤(`fullScroll(View.FOCUS_DOWN)`)되어 진단 결과를 사용자가 즉시 확인 가능.
    * 상태별 색상 코딩 배지(`정상 연결`/`인증 성공`: Green `#4CAF50`, `인증 실패`/`오류`: Red `#FF5252`, `미입력`: Orange `#FFA000`) 및 한눈에 이해하기 쉬운 상세 가이드 텍스트 제공.
    * 완료 후 버튼이 `"네트워크 및 API 키 재테스트"`로 자동 전환되어 키 수정 후 언제든 즉시 재진단 가능.
* **분할화면 상·하 스크롤/스와이프 실시간 수직 이동 애니메이션(`TranslationY`) 및 인터랙티브 전환 구현**
  * **수직 슬라이드 스크롤 애니메이션(`SplitMediaContainer`) 전면 고도화**:
    * 단순 페이드 방식이 아닌, 사용자가 손가락으로 드래그하거나 스와이프할 때 **두 화면이 위아래로 연속해서 밀려나고 들어오는 물리적인 수직 스크롤 애니메이션(`translationY`)** 구현.
    * **실시간 손가락 드래그 추종(Interactive Dragging)**: 분할 화면을 터치하여 위/아래로 밀면 현재 화면과 다음 화면이 손가락 움직임에 1:1로 부드럽게 반응하며 이동.
    * **플링(Fling) 및 스냅(Snap) 물리 역학 지원**: 빠른 스와이프(Fling) 시 관성을 감지하여 매끄러운 감속 곡선(`DecelerateInterpolator(1.6f)`)으로 전환을 완료하며, 드래그 후 취소 시 원위치로 자연스럽게 복귀(Snap Back).
    * **시각적 깊이감(Depth)**: 이동 거리에 따라 나가는 뷰는 은은하게 페이드아웃(`1.0 -> 0.65`), 들어오는 뷰는 페이드인(`0.65 -> 1.0`)되어 프리미엄 자동차 디지털 콕핏의 입체감 연출.
    * **전환 알림 토스트 제거 (무음 제스처 스크롤 완성)**: 화면 전환 시 표출되던 하단 토스트 팝업(`"미디어 플레이어"` / `"오픈파일럿 주행정보"`)을 제거하여, 주행 중 불필요한 팝업 방해 없이 매끄럽고 일체감 있는 화면 스크롤 환경 제공.
    * 마우스 휠 및 트랙패드 수직 스크롤(`ACTION_SCROLL`) 시에도 동일한 방향성 스크롤 애니메이션 작동.
    * 미디어 제어 버튼(재생/일시정지, 이전/다음곡), 프로그레스 바 수평 드래그, 속도 카드 터치 등 기존 클릭 및 가로 제스처와 완벽 분리.
    * 티맵 안전운행(`MapActivity`) 및 카카오내비 경로안내(`KakaoMapActivity`) 전반에 일관 적용.
* **차량 후방 비주얼라이저 양측 원근감 차선(Lane Lines) 렌더링 및 주행 속도 연동 실시간 스트리밍 애니메이션 구현**
  * **3D 원근법 도로 차선(Perspective Road Lane Lines) 시각화**:
    * 차량 후방 이미지 양측에 소실점(Vanishing Point) 원근법을 적용한 노면 트랙 및 5구간 점선(Dashed Lane Markers)을 정밀 렌더링.
    * 원거리로 갈수록 폭과 간격이 자연스럽게 좁아지는 입체 원근 투영 및 상·하단 투명도 페이드(`sin(u * π)`) 적용으로 사이버틱한 자율주행 도로 질감 구현.
  * **실시간 주행 속도(`speedKph`) 연동 차선 흐름 애니메이션**:
    * 오픈파일럿으로부터 수신된 실제 차량 속도(`vEgoKph`)에 비례하여 차선 점선이 뒤에서 앞으로(소실점에서 카메라 시점 방향으로) 매끄럽게 흐르는 동적 애니메이션(`lanePhase`) 구현.
    * 고속 주행 시에는 빠른 속도감의 흐름, 서행 시에는 완만한 흐름으로 실제 주행 속도감을 직관적으로 전달.
    * 차량 정지 상태(`speed == 0`) 시 차선이 멈추며 화면 갱신 루프가 즉시 중지되어 배터리 및 CPU 소모 0% 보장.
  * **실제 차량 규격 방향지시등 점멸(Blinking) 애니메이션 구현**:
    * 실제 자동차 플래셔 릴레이 규격(분당 약 88회, 680ms 주기: 340ms 점등 / 340ms 소등)을 완벽히 모델링하여 테일램프와 차선이 리드미컬하게 깜빡이는 실시간 점멸 애니메이션 구현.
    * 오픈파일럿(Openpilot)이 자율주행 제어 안정성을 위해 신호를 지속 유지(`True`)하여 전달하더라도, 앱 내부 애니메이션 엔진을 통해 실제 차량 깜빡이 동작과 100% 일치하는 깜빡임 연출.
    * **점등 구간(340ms)**: 테일램프 외측 램프와 해당 방향 차선이 선명한 **앰버 옐로우(`amber yellow #FFB800`)**로 발광.
    * **소등 구간(340ms)**: 테일램프 램프 소등 및 차선이 기본 **네온 사이언(`neon cyan #38BDF8`)**으로 복귀하여 시인성 극대화.
    * **정지 상태(`speed == 0`) 점멸 지원**: 신호 대기 등으로 정지해 있을 때도 깜빡이가 켜져 있으면 화면에서 정상적으로 깜빡거리며, 깜빡이를 끄고 정지하면 즉시 화면 갱신 루프를 멈추어 초절전(CPU/배터리 0%) 유지.
  * **초절전 라이프사이클 최적화**: 뷰가 화면에서 분리되거나 가려질 때(`onDetachedFromWindow`, `onVisibilityChanged`) 애니메이션 콜백을 즉시 해제하여 불필요한 배터리 소모 원천 차단.
* **네트워크 가용성 검사 로직 개선 (CarlinKit USB 테더링·VPN 등 전송 인터페이스 호환성 확보)**
  * **Capability 기반 네트워크 검사(`NET_CAPABILITY_INTERNET`)로 전면 전환**:
    * 기존의 특정 물리 인터페이스(`TRANSPORT_WIFI`, `TRANSPORT_CELLULAR`, `TRANSPORT_ETHERNET`) 하드코딩 화이트리스트 검사 방식 폐지.
    * CarlinKit 등 차량용 안드로이드 기기에서 스마트폰과 USB 테더링(`TRANSPORT_USB`, API 31+)으로 연결하거나, WireGuard/Tailscale 등 VPN(`TRANSPORT_VPN`), 블루투스 테더링을 사용하는 환경에서 실제로 인터넷이 연결되어 있음에도 `"네트워크 연결 대기 중..."` 토스트가 무한 반복되며 지도 SDK 초기화가 멈추던 문제를 원천 해결.
    * 구글 안드로이드 공식 권장 규격에 따라 물리 인터페이스의 종류와 관계없이 인터넷 연결 능력(`hasCapability(NET_CAPABILITY_INTERNET)`)을 직접 검사하도록 개선하여 모든 차량 네트워크 환경에서 원활한 지도 초기화 보장.
* **오픈파일럿(Openpilot) 실시간 주행정보 분할 대시보드 & 차량 후방 비주얼라이저 구현**
  * **차량 후방(Rear View) 실시간 비주얼라이저(`CarRearVisualizerView`) 도입**:
    * 계기판 중앙에 모던 EV/스포츠 세단 후방 뷰 벡터 그래픽을 배치하여 실제 차량의 등화 상태를 한눈에 직관적으로 시각화.
    * **실시간 방향지시등 점등**: 좌/우 깜빡이 작동 시 해당 방향 테일램프 외측 램프가 **선명한 앰버 옐로우(주황색)**로 발광하며 주변 글로우 효과 표출.
    * **실시간 제동등 점등**: 감속 제동 및 브레이크 작동 시 메인 테일램프와 라이트 바가 **강렬한 크림슨 레드**로 대폭 증폭 발광하고, 리어 글래스 상단의 **보조 제동등(CHMSL, 3rd Brake Light)** 및 노면 제동 반사광이 실시간 점등.
    * **상시 슬림 미등(Tail Lamp)**: 평상시 은은한 슬림 레드 LED 미등 라인이 점등되어 완성도 높은 디지털 클러스터 연출.
  * **차량 이미지 상단 플로팅 신호등 캡슐 & 중복 텍스트 제거로 초슬림 대시보드 완성**:
    * **중복 연결 상태(OP 연결됨, IP, Ver) 헤더 제거**: 지도 우측 상단 HUD 오버레이에 이미 기기 연결 상태 및 IP/버전 정보가 표출되고 있으므로, 분할 대시보드 상단의 중복 헤더 바를 제거하여 메인 속도/차량 카드가 최상단에 시원하게 위치하도록 여백 최적화.
    * **중복 텍스트 인디케이터 제거**: 차량 후방 벡터 비주얼라이저에서 방향지시등과 제동등이 직관적으로 점등되므로, 기존의 중복 텍스트 배지(`[ ◀ ]`, `[ BRAKE ]`, `[ ▶ ]`)를 완전히 삭제하여 시각적 군더더기 제거.
    * **차량 상단 플로팅 신호등 캡슐(`llOpDashTrafficPill`)**: 기존 하단의 넓은 독립 신호등 카드를 폐지하고, 차량 이미지 바로 위에 3색 물리 램프 및 간결한 신호 상태(`적색 신호` / `황색 신호` / `녹색 신호` / `신호 대기`) 캡슐을 플로팅 배치하여 공간 낭비 해소.
    * **스크롤 없는 완벽한 원페이지(1-Page) 올인원 레이아웃 & 빈 공간 제로화**:
      * AI 제어 판단 로그 제거 후 발생한 하단 빈 공간(Void)을 완벽 해소하기 위해 전체 카드 높이 및 레이아웃 비율을 인체공학적으로 재조정.
      * 차량 후방 비주얼라이저의 높이를 `98dp`로 풍성하게 복원하여 사이버틱 스포츠 세단의 스탠스, 램프 및 노면 반사광을 웅장하게 표출.
      * 대형 디지털 속도계(`48sp` 볼드) 중앙 배치 및 크루즈 설정/실제 제어 속도를 2열 독립 서브카드(`bg_op_subcard`)로 정돈.
      * 하단 E2E 자율주행 모델 카드의 헤더/상태배지/설명 구조를 2열로 확장하여, **스크롤이 전혀 발생하지 않으면서도 화면 전체를 100% 꽉 채우는 프리미엄 콕핏 클러스터 완성**.
  * **미디어 ↔ 오픈파일럿 주행정보 분할화면 선택 옵션 도입 & 미디어 오버레이 상시 공존**:
    * **미디어 오버레이 활성화 시에도 분할 화면 상시 유지**:
      * 기존에는 플로팅 미디어 팝업 오버레이를 켜면 분할 화면이 강제로 닫히고(지도 5.0 전체화면) 분할 핸들이 사라지던 동작을 완전히 개선.
      * 이제 플로팅 미디어 팝업을 띄우더라도 우측의 분할 화면(오픈파일럿 대시보드 또는 미디어 플레이어)이 닫히지 않고 그대로 유지되어, 지도 위 미디어 제어와 실시간 오픈파일럿 계기판을 완벽하게 동시에 활용 가능.
      * 주행 설정창(미디어/화면 탭)에서도 미디어 오버레이 On/Off와 관계없이 분할 비율 및 분할 콘텐츠 선택 옵션이 항상 표출되도록 개선.
    * 주행 설정창(미디어/화면 탭) 및 미디어 팝업 롱클릭 메뉴에 분할화면 표시 콘텐츠 선택 옵션(`SPLIT_CONTENT_TYPE`)을 추가하여 `[미디어 플레이어]`와 `[오픈파일럿 주행정보]` 중 원하는 정보를 자유롭게 선택 가능.
    * 대시보드 속도 영역 터치 시 즉시 주행 설정창으로 연결되는 퀵 링크 지원.
  * **올인원 디지털 클러스터 대시보드 UI**:

  * **미디어 오버레이 자유 드래그 이동 & 위치 저장**: 플로팅 카드를 원하는 위치로 화면 어디든 드래그하여 이동 가능하며, 가로/세로 모드별 위치 자동 기억 및 복원.
  * **위치 초기화 지원**: 음표 버튼을 길게 누르면 미디어 카드가 원래 기본 위치로 즉시 복원.
  * **미디어 오버레이 활성화 시 분할모드 비활성화 및 주행화면 전체화면 자동 전환**: 미디어 플로팅 카드가 켜져 있는 동안에는 미디어 분할모드가 비활성화되어 주행화면이 전체화면으로 넓게 표출되고 분할 경계선 핸들도 함께 숨김 처리되며, 미디어 오버레이를 닫으면 원래 설정된 분할 화면 비율과 핸들이 복원.
  * **미디어 오버레이 앨범아트 터치 시 가로/세로 형태 선택 메뉴 제공**: 미디어 플로팅 카드의 앨범아트를 탭하면 '가로 형태 (수평 바)'와 '세로 형태 (콤팩트 카드)'를 선택할 수 있는 팝업 메뉴가 표출되어 취향 및 차량 거치 환경에 맞게 원하는 형태로 즉시 전환 가능.
  * **오버레이 하단 테두리 실시간 재생 진행바(Progress Bar) 구현**: 오버레이 카드 하단 테두리를 따라 부드럽게 흐르는 슬림(3dp) 실시간 재생 진행바를 추가하여, 별도의 컨트롤 영역 없이도 현재 곡의 재생 진행률과 남은 분량을 한눈에 직관적으로 확인 가능 (미디어 팝업 플레이어와 동일한 세련된 블루 그라데이션 컬러 적용).
  * **세로 형태 카드 레이아웃 및 텍스트 여백 최적화**: 카드 높이를 188dp로 확장하고 하단 패딩 및 폰트 여백을 보정하여, 세로 형태에서도 아티스트명이 잘림 없이 온전하고 선명하게 표출되도록 개선.
  * **곡명 및 아티스트명 긴 텍스트 자동 마퀴(Marquee) 스크롤 지원**: 곡 제목이나 가수 이름이 오버레이 카드 폭보다 길어질 경우 말줄임표 대신 자동으로 부드럽게 흐르는 텍스트 애니메이션(Marquee)을 적용하여 전체 텍스트를 편리하게 확인 가능.
  * **미디어 오버레이 활성화 상태 영구 저장 및 앱 재실행 시 자동 복원**: 미디어 오버레이를 켜둔 상태에서 앱을 종료하거나 재실행해도 활성화 상태(`MEDIA_OVERLAY_VISIBLE`)가 영구 보존되어 이전 상태 그대로 즉시 오버레이가 표출되도록 개선.
  * **원터치 미디어 분할 설정 연동**: 플로팅 카드의 앨범아트 외 영역(곡 정보 등)을 가볍게 탭하면 미디어 화면 분할 및 배경 스타일 설정 창으로 즉시 이동.

* **NavClient앱 연결 안정성 개선**
  * 자체 IP 변경 감지 모니터 추가(1초 주기). 네트워크 환경 변경 시 기기 간 연결 서비스 자동 재등록.

## 3. 관제 서버 (ServerApp)

### 최신 업데이트 사항

* **실시간 로그 수집 및 모니터링 기능 신규 구축**
  * 내비앱의 동작 상태(로그)를 실시간으로 수집하고, 웹 대시보드에서 기기별로 간편하게 조회할 수 있는 통합 관제 시스템 추가.
* **대시보드 브랜딩 및 편의 기능 대폭 강화**
  * 프로젝트 명칭 변경에 맞춰 대시보드 타이틀을 **CommaNav 관제 서버**로 일괄 통일.
  * 기기 목록에 **온라인 / 오프라인** 상태 표시 뱃지를 추가하여 실시간 접속 여부 직관적 확인 가능.
  * 복잡한 16자리 기기 ID 대신 사용자가 원하는 이름으로 변경해 볼 수 있는 **기기 별명(Alias)** 편집 기능 추가.
* **유지보수 및 배포 환경 최적화**
  * 무한정 쌓이는 로그를 방지하기 위해 **7일 경과 로그 자동 삭제(Log Rotation)** 정책 적용.
  * Docker Hub에 공식 이미지(`grt47/comma_nav_server:latest`)를 퍼블리시하고 `docker-compose.yml`을 개선하여 Portainer에서 1초 만에 서버를 구축할 수 있도록 지원.
  * 템플릿 파일 핫-리로딩(`TEMPLATES_AUTO_RELOAD = True`) 적용 및 데이터(`data/`) 영구 보존 볼륨 마운트 구조 도입.
