# CarrotNavi 업데이트 릴리즈 노트

---

## 1. 내비 앱 (NaviApp)

### v2.2.1

* **오픈파일럿(Openpilot) 실시간 주행정보 분할 대시보드 및 방향지시등/제동등 시각화 구현**
  * **미디어 ↔ 오픈파일럿 주행정보 분할화면 선택 옵션 도입**:
    * 주행 설정창(미디어/화면 탭) 및 미디어 팝업 롱클릭 메뉴에 분할화면 표시 콘텐츠 선택 옵션(`SPLIT_CONTENT_TYPE`)을 추가하여 `[미디어 플레이어]`와 `[오픈파일럿 주행정보]` 중 원하는 정보를 자유롭게 선택 가능.
    * 대시보드 속도 영역 터치 시 즉시 주행 설정창으로 연결되는 퀵 링크 지원.
  * **방향지시등(깜빡이) 및 제동등(브레이크등) 실시간 점등 시각화**:
    * 오픈파일럿 차량 CAN 텔레메트리(`left_blinker`, `right_blinker`, `brake_lights`)를 실시간 수신하여 계기판 상단에 즉각 반영.
    * **좌/우 방향지시등(`[ ◀ ]`, `[ ▶ ]`)**: 깜빡이 작동 시 고선명 에메랄드 그린(`bg_op_blinker_active`) 발광 링 및 텍스트 점등.
    * **제동등(`[ BRAKE ]`)**: 감속 제동 및 브레이크 작동 시 크림슨 레드(`bg_op_brake_active`) 글로우 배지 및 볼드 화이트 텍스트 점등.
  * **올인원 디지털 클러스터 대시보드 UI**:
    * **크루즈 인게이지 배지 & 대형 속도계**: 오픈파일럿 활성화 상태(`ENGAGED` 네온 사이언 / `DISENGAGED` 그레이) 및 대형 속도계(54sp), 크루즈 설정 속도, 실제 제어 속도를 한눈에 파악.
    * **신호등 인식 3색 신호 램프**: 적색(정지), 황색(주의), 녹색(진행) 신호등 인식 상태를 3색 물리 램프 그래픽 및 텍스트로 선명하게 표시.
    * **E2E 주행 모델 판단 상태**: 정속 주행 / 전방 감속 / 정지 유지(HOLD) / 완만 정지 등 오픈파일럿의 종방향/횡방향 제어 상태를 컬러 배지로 제공.
    * **Carrot AI 제어 판단 터미널 로그**: 차량 AI의 실시간 가속/감속/신호/커브 판단 로그를 터미널 스타일의 모노스페이스 카드로 실시간 표출.
* **휴대폰 뒤로가기 버튼 2회 연속 클릭 시 앱 완전 종료 기능 구현**
  * **뒤로가기 1회 입력 시 안내 토스트 표출**: 주행 중 또는 메인 화면에서 실수로 뒤로가기 키가 눌려 앱이 꺼지는 것을 방지하기 위해 `"앱을 종료하시겠습니까? '뒤로' 버튼을 한번 더 누르면 종료됩니다."` 안내 토스트를 띄우고 2초 대기.
  * **2초 이내 재입력 시 프로세스 완전 종료**: 2초 내에 뒤로가기 버튼을 한 번 더 누르면 UDP 송신(`UdpSenderService`) 및 웹서버(`WebServerService`) 백그라운드 서비스를 안전하게 정지하고 모든 화면을 정리(`finishAffinity()`)한 뒤 프로세스를 완전히 종료(`System.exit(0)`).
  * **전체 화면 일관 적용**: 티맵 안전운행(`MapActivity`), 카카오내비 경로안내(`KakaoMapActivity`), 메인 진입 화면(`MainActivity`) 모두 동일하게 적용.
* **주행화면 원터치 목적지 버튼(집, 사무실, 즐겨찾기) 하단 상태바 내부로 통합 이전**
  * **상단 플로팅 캡슐 버튼 제거 및 하단 바 통합**: 기존 지도 상단(TBT 안내 패널 주변)에 떠 있던 원터치 목적지 버튼 그룹(`[집]`, `[사무실]`, `[즐겨찾기]`)을 하단 통합 상태바(GPS 오버레이 바) 내부로 완전히 옮겨 지도 시야 가림을 원천 해소.
  * **가로/세로 최적화 반응형 레이아웃**:
    * **가로 모드 (1줄 구조)**: `[GPS 수신상태 배지] | [원터치 목적지: 집 / 사무실 / 즐겨찾기] | [현위치 주소 칩]` 3개 구역으로 균형 배치.
    * **세로 모드 (2줄 구조)**: 상단 1열에 `[GPS 상태 배지] + [원터치 목적지 버튼군]`, 하단 2열에 `[위치 핀 아이콘 + 현위치 실시간 도로명 주소]`를 배치하여 좁은 화면 폭에서도 잘림 없이 선명하게 표출.
  * **원터치 목적지 버튼 디자인 및 인터랙션 고도화**:
    * 집, 사무실 캡슐 버튼의 가로 폭을 즐겨찾기 버튼 폭과 동일하게 동기화하여 시각적 일체감 완성.
    * 캡슐 버튼 전용 배경 테두리 및 터치 리플 이펙트 적용으로 주행 중 조작성 향상.
* **목적지 미리보기 화면 전체 경로 잘림 현상 완벽 해결 및 지도 프레이밍 고도화**
  * **가로/세로 모드 전체 경로선 잘림 방지 (동적 마진 보정)**: KNSDK 내비 지도의 카메라 중심(앵커)이 화면 물리적 중심보다 아래쪽에 배치되어 분할 화면에서 출발지/도착지 또는 경로 상·하단이 잘리던 문제를 완벽 해결. 가로 모드(좌우 6:4)와 세로 모드(상하 5.5:4.5)의 뷰포트 비대칭 오프셋을 정밀 계산하여 남쪽(minY) 및 상하좌우 마진을 동적으로 최적화(`maxSpan` 기반 최소 마진 보장).
  * **전체 경로 2D 탑뷰 시야 확보**: 경로 탐색 완료 시 전체 경로와 출발(Blue)/도착(Red) 핀이 상하좌우 15~20%의 편안한 여백과 함께 지도 영역 정중앙에 잘림 없이 온전히 표출.
  * **미리보기 화면 지도 더블탭 오작동 방지**: 경로 미리보기 중 지도 영역을 더블탭했을 때 3D 주행 모드나 내 위치 추적 모드로 강제 전환되는 현상을 차단하여 2D 탑뷰 전체 경로 모드가 흔들림 없이 유지되도록 제어.
  * **미디어 분할 경계 프레임 및 핸들 간섭 제거**: 목적지 미리보기 분할화면 진입 시 기존 미디어 분할 핸들과 외곽 프레임이 중첩되어 보이던 현상을 수정하여 깔끔한 미리보기 전용 화면 제공.
* **주행 상세 설정 화면 전면 개편 (모던 다크 UI & 3대 카테고리 탭 도입)**
  * **3개 카테고리 탭 구조**: 수많은 옵션이 길게 나열되던 기존 방식을 개선하여 목적에 맞는 3개 탭으로 분리.
    * **🚗 주행 / 오디오**: 주행 단위(km 표기), 구간단속 보상가속 기능, 오디오 더킹 모드 및 안내 음량 조절.
    * **🎵 미디어 / 화면**: 미디어 팝업 오버레이 스위치, 뒷배경 스타일(앨범아트/EQ 3종), 화면 분할 비율, 하단 정보 바 높이 미세 조절.
    * **⚙️ 시스템 / 정보**: Openpilot 통신 연결 상태, 백그라운드 위치 권한, 웹서버 접속 IP/포트, 앱 업데이트 확인 및 앱 종료.
  * **전체화면(FullScreen) 독립 페이지 전환**: 기존 하단 시트(BottomSheet) 형태에서 가독성과 몰입감이 뛰어난 전체화면 다이얼로그(`Theme.CarrotNavi.FullScreenDialog`)로 전환 (`fitsSystemWindows` 적용으로 상태바/네비게이션바 간섭 완벽 해소).
  * **가로 모드(Landscape) 2열 그리드 전용 레이아웃 도입**: 가로 거치 환경에서 각 탭의 항목들이 좌/우 2열 그리드로 자동 분할되어 스크롤 없이 한눈에 모든 설정을 확인 및 조작 가능.
* **설정 옵션 고도화 및 세부 제어 기능 추가**
  * **미디어 팝업 오버레이 설정창 On/Off 스위치 추가**: 화면의 플로팅 미디어 카드 표시 여부를 설정창에서도 손쉽게 켜고 끌 수 있도록 스위치 옵션 제공.
  * **화면 분할 비율 조절 설정 조건부 표출**: 미디어 팝업 오버레이가 켜져 있을 때(지도 전체화면 유지)는 분할 비율 조절 항목을 자동으로 숨김(GONE) 처리하고, 오버레이가 꺼져있을 때만 표출(VISIBLE)하여 설정창의 시각적 복잡도 감소.
  * **하단 정보 바 높이 미세 조절 통합 및 가로/세로 분리 제어**:
    * 티맵과 카카오내비로 나뉘어 있던 조절 항목을 하나의 통합 오프셋으로 일원화하여 양쪽 내비 엔진의 하단 바 크기 및 높이를 1:1 완벽 동기화.
    * 세로 모드(기본 78dp)와 가로 모드(기본 40dp)를 각각 독립적으로 세밀하게 조절 가능하도록 지원.
* **하단 정보 바 및 UI 정밀 다듬기**
  * **오버레이 토글 버튼(`btnToggleVisibility`) 삭제**: 화면 시야를 가리던 레거시 토글 버튼을 UI에서 제거하여 한층 더 깔끔한 지도 화면 제공.
  * **하단 정보 바 상하단 빈 여백 최소화**: 세로 모드(78dp) 및 가로 모드(40dp)의 패딩을 2dp로 타이트하게 조절하여 불필요한 빈 여백을 없애고 지도 표시 영역 극대화.
  * **현위치 주소 텍스트 및 위치 핀 아이콘 중앙 정렬**: 세로 모드 2줄 구조에서 텍스트와 핀 아이콘이 완벽히 중앙에 정렬되도록 레이아웃 개선.

### v2.2.0

* **목적지 미리보기 화면 분할화면(Split View) 구조 개편 및 4대 경로 탐색 옵션(추천경로, 무료우선, 유료우선, 최단경로) 지원**
  * **지도 ↔ 경로 상세 분할화면(Split View) 레이아웃 도입**: 기존 플로팅 카드 오버레이 형태에서 벗어나 주행화면 컨테이너 레벨의 분할화면 구조로 전면 개편.
    * **가로 모드**: 지도 60% : 경로 상세 패널 40% (수평 좌우 분할)
    * **세로 모드**: 지도 55% : 경로 상세 패널 45% (수직 상하 분할)
  * **전체 경로 지도 자동 프레이밍 및 커스텀 뱃지 핀 고도화**:
    * **출발지/도착지 및 경로 전구간 균형 잡힌 자동 프레이밍**: KNSDK 뷰포트 및 분할 패널을 고려한 상/하/좌/우 비대칭 마진 보정을 통해, 출발지(파란 뱃지 핀)와 도착지(빨간 뱃지 핀), 전체 경로선이 상하좌우 15~20%의 편안한 여백과 함께 잘림 없이 한 화면 중앙에 온전히 표출.
    * **주행 전용 UI 및 차량 커서 숨김**: 경로 미리보기 중 주행 차량 커서 화살표, 줌 버튼, 속도계, 나침반, 상단 HUD 위젯 등 주행 전용 요소를 깔끔하게 숨김 처리.
    * **고해상도 커스텀 뱃지 핀 적용**: 입체 그림자, 화이트 테두리 및 포인터, 볼드 타이포그래피가 적용된 세련된 "출발"(Blue) 및 "도착"(Red) 마커 핀 표출.
  * **경로선 가림 없는 균형 잡힌 지도 표출**: 지도 영역과 패널이 완전히 물리적으로 분리되어 경로선이나 마커가 카드에 가려지지 않으며, 전체 경로를 지도 영역 정중앙에 시원하고 직관적으로 표출.
  * **4개 경로 옵션 탭 제공**: 목적지 검색 및 외부 전송(ACTION_SEND, 즐겨찾기 등) 시 표출되는 목적지 미리보기 패널에 `[추천경로]`, `[무료우선]`, `[유료우선]`, `[최단경로]` 4가지 탐색 옵션 탭 제공.
  * **실시간 경로 비교 및 캐싱**: 탭 선택 시 카카오내비(KNSDK) 경로를 즉시 탐색하거나 메모리 캐시된 경로를 불러와 소요시간, 도착예정시각, 주행거리, 통행료 정보 및 지도 경로선을 실시간 갱신.
  * **5초 카운트다운 타이머 & 수동 비교 모드**: 기본 진입 시 5초 카운트다운 후 자동 길안내가 시작되며, 사용자가 경로 옵션 탭을 터치하여 선택하면 타이머가 즉시 정지되어 자동 시작되지 않고 여유롭게 경로 정보를 비교한 뒤 '안내 시작'을 누를 수 있도록 개선.
  * **안내 시작/취소 시 주행 모드 자동 복원**: 길안내가 시작되거나 취소되면 미리보기 분할화면이 닫히고 원래 설정된 미디어 분할화면 및 HUD 레이아웃으로 부드럽게 복원.
  * **모던 카카오 테마 다크 글래스 UI**: 반투명 딥 다크 배경, 카카오 옐로우 포인트 컬러, 라운드 코너 카드 디자인을 적용하여 세련되고 일체감 있는 사용자 경험 제공.
* **설정 버튼 상단 미디어 재생현황 플로팅 오버레이 추가**
  * **미디어 오버레이 원터치 버튼**: 우측 하단 설정 버튼 상단에 음표 모양의 미디어 토글 버튼 배치.
  * **플로팅 미디어 카드 (재생현황 특화)**: 불필요한 컨트롤 버튼을 과감히 제거하고 재생현황(앨범아트, 곡 제목, 아티스트, 실시간 재생/일시정지 상태 뱃지)에 집중하여 더욱 슬림하고 미려한 디자인 적용.

  * **세로 형태 카드 레이아웃 및 텍스트 여백 최적화**: 카드 높이를 188dp로 확장하고 하단 패딩 및 폰트 여백을 보정하여, 세로 형태에서도 아티스트명이 잘림 없이 온전하고 선명하게 표출되도록 개선.
  * **곡명 및 아티스트명 긴 텍스트 자동 마퀴(Marquee) 스크롤 지원**: 곡 제목이나 가수 이름이 오버레이 카드 폭보다 길어질 경우 말줄임표 대신 자동으로 부드럽게 흐르는 텍스트 애니메이션(Marquee)을 적용하여 전체 텍스트를 편리하게 확인 가능.

  * 기존에 앱 설정의 '구간단속 속도 상향(오프셋/펀치력)' 값이 0일 때, 오픈파일럿이 구간단속을 인식하는 데 필요한 필수 파라미터(`nSdiBlockSpeed`) 데이터가 통째로 누락되어 전송되던 구조적 버그 해결.
  * 펀치력 설정 여부와 상관없이 무조건 원래의 제한속도 값을 복사해 전송하도록 안전 장치를 추가하여 순정 상태에서도 정상 작동하도록 개선.

### v2.1.0

* **관제 서버 통신 최적화 및 설정 단순화**
  * 리버스 프록시(HTTPS) 환경 지원을 위해 관제 서버 URL(`https://comma-nav-server.leegrt.org`)을 앱 내부에 하드코딩하여 통신 안정성 확보.
  * 앱 내 원격 설정 페이지(8080 포트)에서 불필요해진 '관제 서버 URL' 입력란을 제거하여 사용자 편의성 증대 및 오작동 방지.

### v2.0.10

* **앱 완전 종료 시 백그라운드 좀비 프로세스 현상 수정**
  * '앱 완전 종료' 버튼 클릭 시 UDP 통신 및 웹 서버 서비스가 명시적으로 종료되도록 수정하여, 앱 종료 후에도 시스템에 의해 강제 재실행되는 버그 해결.
* **지도 화면 HUD 버튼 레이아웃 최적화**
  * 우측 하단의 4개 버튼을 기존 2x2 형태에서 세로 1열 4행(설정, 주소 검색, 편집, 숨김) 배열로 변경하여 지도 시야 개선 및 직관성 향상.
* **목적지 검색 화면 잘림 현상 개선**
  * 검색창 및 결과 리스트가 기기의 시스템 영역(상단 상태 바, 하단 내비게이션 바)을 침범하여 가려지는 UI 오류 수정.
* **상세 설정 팝업 내 기기 IP 주소 표출**
  * 원격 접속 편의를 위해 상세 설정 팝업 최하단에 현재 동작 중인 기기의 내부 IP 주소와 mDNS 주소를 표시하도록 기능 추가.

### v2.0.9

* **카카오내비 구간단속 오픈파일럿 연동 지원**
  * 카카오내비 사용 시 구간단속 이벤트(`KNSafetyType_Section`)를 정상적으로 인식하여, TMAP과 동일하게 구간단속 평균/제한 속도 데이터를 오픈파일럿으로 송신하도록 구현.
* **오픈파일럿 통신 데이터 파이프라인 안정화**
  * 1차 단속 제한 속도(`nSdiSpeedLimit`)가 0으로 내려올 경우, 구간단속 제한속도(`nSdiBlockSpeed`) 값을 차용하도록 예외 처리 추가.

### v2.0.8

* **오픈파일럿 최신 버전 호환성 패치**
  * 최신 오픈파일럿(`carrot-wip` 브랜치) 환경에서 구간단속 중간 지점 통과 시 단속 정보를 인식하지 못하고 락이 풀리는 문제 수정 (`nSdiSpeedLimit` 폴백 로직 추가).
* **미디어 아티스트명 표출 오류 수정**
  * FLO 등 특정 음악 플레이어 앱 사용 시, 아티스트 정보가 누락되어 UI에 표시되지 않던 버그 수정 (빈 문자열 처리 개선).

### v2.0.5

* **내비게이션 안내 음성 볼륨 조절 기능 추가**
  * 기존에 음소거 처리되어 있던 길 안내 음성을 사용자가 직접 조절할 수 있도록 변경.

## 3. 관제 서버 (ServerApp)

### 최신 업데이트 사항

* **실시간 로그 수집 및 모니터링 기능 신규 구축**
  * 내비앱의 동작 상태(로그)를 실시간으로 수집하고, 웹 대시보드에서 기기별로 간편하게 조회할 수 있는 통합 관제 시스템 추가.
* **대시보드 브랜딩 및 편의 기능 대폭 강화**
  * 프로젝트 명칭 변경에 맞춰 대시보드 타이틀을 **CommaNav 관제 서버**로 일괄 통일.
  * 기기 목록에 **온라인 / 오프라인** 상태 표시 뱃지를 추가하여 실시간 접속 여부 직관적 확인 가능.
  * 복잡한 16자리 기기 ID 대신 사용자가 원하는 이름으로 변경해 볼 수 있는 **기기 별명(Alias)** 편집 기능 추가.
* **유지보수 및 배포 환경 최적화**
  * 무한정 쌓이는 로그를 방지하기 위해 **7일 경과 로그 자동 삭제(Log Rotation)** 정책 적용.
  * Docker Hub에 공식 이미지(`grt47/comma_nav_server:latest`)를 퍼블리시하고 `docker-compose.yml`을 개선하여 Portainer에서 1초 만에 서버를 구축할 수 있도록 지원.
  * 템플릿 파일 핫-리로딩(`TEMPLATES_AUTO_RELOAD = True`) 적용 및 데이터(`data/`) 영구 보존 볼륨 마운트 구조 도입.
