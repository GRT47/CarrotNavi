# 🥕 CarrotNavi (CommaNav) 전체 기능 가이드 및 기능 명세서

> **CarrotNavi**는 안드로이드 기반 올인원(AIO) 디바이스 및 태블릿을 위해 설계된 지능형 차량용 내비게이션 애플리케이션입니다.  
> Tmap의 독보적인 고정밀 안전운행(SDI) 데이터와 카카오내비의 최신 경로안내(TBT) 엔진을 결합한 **듀얼 엔진 아키텍처**를 기반으로 하며, 자율주행 보조 시스템인 **오픈파일럿(openpilot)**과의 실시간 UDP 양방향 연동을 완벽하게 지원합니다.

## 1. 핵심 아키텍처 (듀얼 엔진 & UDP 통신)

### 1-1. Tmap + 카카오내비 무중단 듀얼 엔진 구조
CarrotNavi는 두 지도 엔진의 장점만을 결합한 고유의 이중 실행 구조를 가집니다.
- **백그라운드 (`MapActivity`)**: **Tmap SDK 안전운행 모드** 상시 구동
  - 단속 카메라, 실시간 제한속도, 어린이보호구역, 사고다발구간 등 국내 최고 수준의 안전운행(SDI) 데이터를 지속 추출하여 데이터 파이프라인으로 공급합니다.
- **포그라운드 (`KakaoMapActivity`)**: **카카오내비 KNSDK 경로안내 모드**
  - 목적지 설정 시 Tmap 위에 카카오내비가 매끄럽게 오버레이되어 턴바이턴(TBT) 회전 안내, 교차로 뷰, 차선 안내를 제공합니다.
- **자연스러운 안전운행 자동 복귀**:
  - 경로 안내가 종료되거나 사용자가 안내를 취소하면, 백스택의 Tmap 안전운행 모드로 앱 재시작 없이 즉시 복귀합니다.

### 1-2. 오픈파일럿(openpilot) 실시간 UDP 통신 (`UdpSenderService`)
차량의 자율주행 보조 시스템(openpilot / dragonpilot / frogpilot 등)과 직접 통신합니다.
- **300ms 고주기 실시간 브로드캐스트**:
  - 주행 속도, 규정 제한속도, 카메라 종류/남은 거리, 구간단속 잔여 거리/시간/평균속도, 다음 턴 방향/거리, 목적지 잔여 거리/시간 등을 JSON 패킷으로 패키징하여 오픈파일럿(`7706` 포트)으로 지속 송신합니다.
- **Navitype 불변성 보장 (`navitype: "tmap"`)**:
  - 카카오내비 안내 중에도 openpilot 수신부와의 완벽한 호환성을 위해 `navitype`을 `"tmap"`으로 고정 전송하여 SDI 및 TBT 데이터가 누락 없이 HUD에 동시 표출됩니다.
- **더미 패킷 주입 로직**:
  - 목적지 잔여 거리/시간이 일시적으로 0이 될 때도 오픈파일럿의 TBT 안내 패널이 꺼지지 않도록 최소 더미 값을 유지합니다.

## 2. 주행 지원 & 스마트 속도 제어 (보상가속)

### 2-1. 구간단속 지능형 보상가속 (Speed Compensation Boost)
구간단속 구간에서 규정 속도 이하로 주행하여 발생한 평균속도 손실을 안전하고 똑똑하게 만회할 수 있도록 오픈파일럿에 추가 가속력을 유도합니다.
- **보상가속 기능 On/Off**: 사용자가 원할 때 언제든 스위치로 활성화/비활성화.
- **보상가속 여유 속도 (Offset: 0 ~ 50 km/h)**:
  - 구간단속 중 오픈파일럿에 전달할 최대 추가 가속 한계값을 설정합니다.
- **보상가속 2가지 작동 모드**:
  1. **점진적 보상가속 (Progressive)**: 평균속도가 목표치에 근접할수록 추가 가속량을 부드럽게 줄여 목표 도달 시 정지하는 스마트 모드.
  2. **고정 보상가속 (Fixed)**: 구간단속 종료 지점까지 설정된 추가 속도를 일정하게 유지하는 모드.
- **목표 평균속도 하향값 (Fake Drop: 0 ~ 20 km/h)**:
  - 단속 기준 속도 대비 평균속도를 얼마나 더 공격적/안정적으로 유지할지 미세 조정.

### 2-2. 거리 표기 단위 자동 변환
- **km / m 단위 자동 스위칭**: 남은 거리가 1000m 이상일 때 자동으로 `km` 단위(소수점 1자리)로 간결하게 표시하는 옵션 제공.

## 3. 지도 화면 & 디스플레이 최적화

### 3-1. 지도 화면 테마 3가지 모드 (`MAP_THEME_MODE`)
- **🔄 자동 모드 (Auto)**: GPS 기반 일출/일몰 시간 계산 및 터널 진입/진출을 실시간 감지하여 주/야간 테마를 자동 전환.
- **☀️ 주간 모드 (Day)**: 터널이나 야간에도 항상 시인성 높은 밝은 지도 고정.
- **🌙 야간 모드 (Night)**: 눈부심 방지를 위해 항상 어두운 다크 지도 테마 고정.
- Tmap과 카카오내비 양쪽 지도 엔진에 실시간 무중단 동기화 적용.

### 3-2. 전체화면(Immersive Fullscreen) 모드
- **상단바 / 하단 소프트키 완전 숨김**:
  - 안드로이드 시스템 상단 상태바(시계, 배터리)와 하단 내비게이션 바(홈, 뒤로가기)를 완전히 숨겨 화면 끝까지 지도를 꽉 차게 표시.
- **무중단 실시간 토글**: 설정 변경 즉시 앱 재시작 없이 0.1초 만에 화면 전체로 확장.
- **제스처 복원 지원 (`IMMERSIVE_STICKY`)**: 화면 가장자리를 스와이프하면 일시적으로 시스템 바가 나타나고 잠시 후 다시 자동 숨김.

### 3-3. 화면 배율 / DPI 조절 기능 (`CUSTOM_DPI_SCALE`)
- **11단계 정밀 스케일 조정**: 75%부터 125%까지 5% 단위로 UI 크기 확대/축소 지원.
  - 와이드 올인원 모니터: 글자/버튼을 축소하여 지도 영역 극대화 (75% ~ 90%)
  - 대형 태블릿: 멀리서도 잘 보이도록 버튼/글자 확대 (110% ~ 125%)
- 배율 변경 시 안전한 앱 재시작 안내 팝업 제공.

### 3-4. 하단 정보 바 높이 미세 조절 (Height Offset)
- 세로 모드(기본 78dp 기준 -20 ~ +60dp) 및 가로 모드(기본 40dp 기준 -20 ~ +60dp)의 하단 바 높이를 슬라이더로 조절하여 기기별 소프트키나 화면 베젤 간섭을 완벽 회피.

## 4. 멀티태스킹 & 인터랙티브 화면 분할 시스템

### 4-1. 듀얼 멀티 윈도우 구조 (`SplitMediaContainer`)
- **지도 + 미디어/오픈파일럿 동시 표출**:
  - 가로 모드: 좌측 지도 + 우측 분할창
  - 세로 모드: 상단 지도 + 하단 분할창
- **분할 화면 표시 콘텐츠 원터치 전환**:
  - 🎵 **미디어 플레이어**: 음악 재생 제어, 앨범아트, 가사/EQ 표출
  - 🚗 **오픈파일럿 주행정보**: 실시간 차량 주행 데이터 및 3D 도로 시각화

### 4-2. 수직 슬라이드 스와이프 애니메이션
- 분할 영역을 위/아래로 스와이프하거나 마우스 휠을 스크롤하면 **물리적인 수직 슬라이드(`translationY`)와 시각적 깊이감(Depth 페이드)**을 통해 두 화면이 부드럽게 회전 전환됩니다.
- 토스트 팝업 없는 무음 제스처 전환으로 주행 몰입감 극대화.

### 4-3. 0.02단위 초정밀 경계선 핸들 (`SplitHandleManager`)
- **픽셀 수준 미세 비율 조절**:
  - 경계선 핸들을 잡고 드래그하면 기존의 거친 0.5 단위 점프 스냅 없이, **`0.02` 단위(약 0.4% 정밀도)**로 손가락을 놓은 위치 그대로 화면 비율이 유지됩니다.
- **완전 닫힘 시 핸들 상시 유지**:
  - 오른쪽 끝까지 밀어 미디어 창을 닫아도 핸들이 사라지지 않고 화면 가장자리에 슬림하게 상시 남아 있어 언제든 다시 끌어당겨 열 수 있습니다.
- **원터치 탭 복원**:
  - 닫힌 상태에서 핸들을 톡 탭(터치)하면 이전에 사용하던 비율(예: 3.5 : 1.5)로 한 번에 복원됩니다.

### 4-4. 차량 후방 비주얼라이저 (오픈파일럿 뷰)
- **3D 원근법 도로 차선 렌더링**: 소실점 투영법 기반 5구간 점선 차선 표시.
- **실제 주행 속도(`speedKph`) 연동 차선 흐름 애니메이션**: 차량 속도에 비례하여 도로 점선이 앞으로 매끄럽게 흐르는 동적 비주얼 연출.
- 조향각, 크루즈 세팅 속도, 차간거리 등 핵심 주행 데이터 실시간 표출.

## 5. 스마트 미디어 & 오디오 시스템

### 5-1. 안드로이드 미디어 세션 실시간 연동
- YouTube Music, Spotify, Melon, 지니, FLO, 벅스 등 안드로이드 표준 음악 앱과 실시간 연동.
- 재생 중인 곡명, 아티스트명, 고화질 앨범아트 수신 및 재생/일시정지/이전곡/다음곡 컨트롤.
- 프로그레스 바(Seekbar)를 통한 탐색 지원.

### 5-2. 4가지 미디어 뒷배경 스타일
1. **🎨 앨범아트 원본**: 곡의 앨범 아트를 배경으로 꽉 차게 렌더링.
2. **📊 EQ 시각화 (막대 Bar)**: 음악 주파수에 반응하는 다이내믹 막대 이퀄라이저.
3. **🌊 EQ 시각화 (물결 Wave)**: 감성적인 부드러운 오디오 웨이브 그래픽.
4. **⭕ EQ 시각화 (원형 Circle)**: 비트에 맞춰 고동치는 원형 펄스 이퀄라이저.
- *EQ 사용 시 앨범아트 동시 블러(Blur) 오버레이 옵션 지원.*

### 5-3. 플로팅 미디어 팝업 오버레이
- 분할 화면 대신 지도 화면 위에 콤팩트한 카드 형태로 떠 있는 플로팅 위젯 지원.
- 손가락으로 자유롭게 원하는 위치로 드래그 이동 가능하며, 가로형/세로형 형태 전환 지원.

### 5-4. 지능형 오디오 덕킹 (Audio Ducking)
내비게이션 안내 음성이 나올 때 다른 음악 앱의 소리를 지능적으로 제어합니다.
1. **사용 안함**: 음악 음량을 그대로 유지.
2. **볼륨 줄이기 (오디오 포커스)**: 안내 음성이 나오는 동안 음악 볼륨을 자동으로 줄임.
3. **강제 일시정지 후 재생**: 샤오미/중국산 올인원 기기 특화 모드로, 안내 음성 시 음악을 일시 정지했다가 안내 종료 후 재개.
- **내비 안내 음량 독립 슬라이더 (0.0 ~ 1.0)** 제공.

## 6. 목적지 검색 & 외부 연동

### 6-1. 통합 장소/목적지 검색 (`SearchActivity`)
- 카카오 로컬 키워드 검색 REST API 기반 실시간 POI 검색.
- **원터치 퀵 버튼**: 집(Home), 사무실(Office), 즐겨찾기(Favorites) 빠른 길안내.
- 최근 검색 기록 및 상세 거리/위치 확인.
- 검색 결과 선택 시 Tmap 안전운행 구동 확인 후 카카오내비로 안전하게 자동 연결.

### 6-2. 외부 지도 앱 공유 연동 (`ACTION_SEND`)
- 스마트폰이나 태블릿의 네이버지도, 카카오맵, 티맵 등에서 **'공유하기 ➜ CarrotNavi'**를 누르면, 주소와 좌표를 자동으로 파싱하여 즉시 목적지 길안내를 시작합니다.

### 6-3. 원격 목적지 검색 API (`/api/search`)
- 외부 웹서버나 스마트폰 웹 브라우저에서 HTTP POST로 목적지 명칭 및 좌표를 전송하면 차량 내비가 원격으로 경로 안내를 자동 시작합니다.

## 7. HUD 주행 정보 & 안전운행 인포그래픽

### 7-1. 실시간 주행 정보
- **디지털 대형 속도계**: 실시간 GPS 속도 표출.
- **도로 규정 제한속도 원형 표지판**: 현재 주행 도로의 제한속도 그래픽 표출.
- **과속 경고 인포그래픽**: 제한속도 초과 시 테두리 점멸 및 경고.

### 7-2. 단속 카메라 정밀 경보
- 고정식 단속, 이동식 부스, 신호·과속 단속, 구간단속, 버스전용차로, 어린이보호구역 단속 등 완벽 대응.
- 카메라까지 남은 거리(m) 실시간 카운트다운 및 음성/경고음 출력.

### 7-3. 구간단속 전문 인포그래픽 패널
- 구간단속 시작 시 전용 HUD 패널 자동 활성화.
- **현재 구간 평균속도** 실시간 계산 및 표출.
- **단속 종료 지점까지 남은 거리 및 잔여 시간(초)** 실시간 카운트다운.

### 7-4. 하단 퀵 액션 HUD 바
- **좌측**: GPS 수신 상태 인디케이터 (위성 연결 상태 실시간 감지).
- **중앙**: 집 / 사무실 / 즐겨찾기 원클릭 퀵 버튼 (텍스트 줄바꿈 방지 최적화).
- **하단**: 현재 차량이 위치한 도로명 주소 실시간 표시.
- **우측 플로팅 버튼군**:
  - 🎵 미디어 오버레이 On/Off
  - ⚙️ 인체공학적 3탭 상세 설정창 열기
  - 🔍 통합 검색창 열기

## 8. 원격 웹 서버 & 클라우드 원격 관제

### 8-1. 로컬 웹 원격 설정 서버 (`AppWebServer`)
차량과 동일한 Wi-Fi나 핫스팟에 연결된 스마트폰/노트북 웹 브라우저(`http://<기기IP>:8080`)에서 접속 가능합니다.
- **실시간 원격 제어 가능 항목**:
  - UDP 전송 대상 IP 및 포트 설정
  - 구간단속 보상가속 설정 (여유속도, 모드, 평균속도 하향값)
  - 디버그 오버레이 On/Off
  - 화면 크기 / DPI 배율 설정 (75% ~ 125%)
  - 전체화면 모드 On/Off
  - 지도 화면 테마 (자동 / 주간 / 야간)
  - 실시간 경로 안내 정보 JSON 조회 (`/api/route_info`)

### 8-2. 원격 관제 및 오류 로깅 (`RemoteLogManager`)
- 각 디바이스별 고유 기기 ID 부여 (기기 ID 신규 재발급 지원).
- 주행 이벤트, GPS 수신 상태, SDK 초기화 및 예외 오류를 원격 관제 서버(`http://<server>:5000`)로 비동기 안전 전송.
- 네트워크 단절 시 메모리 버퍼링 후 재접속 시 자동 일괄 전송.

### 8-3. 무선 원클릭 자동 업데이트 (`AutoUpdater`)
- **GitHub 최신 릴리즈 점검**: GitHub API를 통해 최신 APK 릴리즈 버전을 자동 감지.
- **사설 관제 서버 업데이트 점검**: 자체 관제 서버를 통한 빌드 버전 배포 지원.
- 다운로드 진행률 프로그레스 및 원클릭 설치 지원.

## 9. 초기 환경설정 & 네트워크 진단 도구

### 9-1. 올인원 네트워크 및 API 키 진단 테스트 (`MainActivity`)
초기 설정 화면에서 버튼 한 번으로 4단계 통신 파이프라인을 원클릭 진단합니다.
1. **🌐 인터넷 네트워크**: 네트워크 연결 유형(Wi-Fi, LTE, 테더링, 이더넷), 로컬 IP, 외부망 RTT 핑 지연 시간(ms) 측정.
2. **🗺️ Tmap SDK (안전운행)**: 입력된 Tmap App Key로 라이선스 서버 인증 성공 여부 판정.
3. **🚗 Kakao 내비 SDK (경로안내)**: 카카오 모빌리티 인증 서버 통신 및 에러 코드 진단.
4. **🔍 Kakao REST API (장소검색)**: 카카오 로컬 키워드 검색 API로 '서울역' 테스트 검색을 즉시 수행하여 HTTP 응답 코드 및 키 유효성 검증.
- 상태별 직관적인 색상 배지(Green 정상, Red 오류, Orange 미입력) 표출.
