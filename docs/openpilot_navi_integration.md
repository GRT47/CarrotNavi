# 오픈파일럿(Carrot 모듈) - 단방향 안전운전 정보(SDI) 연동 규격서

본 문서는 오픈파일럿(`ajouatom/openpilot` 기준)에 **단방향(앱 ➡️ 오픈파일럿)으로 안전운전 정보만 쏘아주는** 앱을 제작할 때 필요한 핵심 규격서입니다. 오픈파일럿으로부터 상태 피드백을 받지 않는 단순 '단말 센서' 형태의 앱을 개발할 때 적용할 수 있습니다.

## 1. 개요 (Overview)
- **목적**: 앱에서 수집한 과속 카메라, 방지턱 정보를 오픈파일럿에 전달하여 자율주행 시 자동 감속을 유도합니다.
- **통신 방식**: **UDP 단방향 통신 (Unidirectional UDP)**
- **특징**: 앱은 오픈파일럿으로 데이터를 던지기만 할 뿐(Send-only), 오픈파일럿이 어떻게 작동하는지 응답(ACK)을 기다리거나 받을 필요가 없습니다.

---

## 2. 네트워크 포트 구성

| 포트 번호 | 프로토콜 | 방향 | 설명 |
| :---: | :---: | :---: | :--- |
| **7706** | UDP | 앱 ➡️ 오픈파일럿 | 앱이 오픈파일럿 기기의 IP 주소를 향해 안전운전 정보(SDI) 데이터를 일방적으로 전송 |

---

## 3. 전송 데이터 (JSON 규격)
**앱은 UDP 7706 포트를 통해 아래와 같은 구조의 JSON 데이터를 문자열(UTF-8)로 인코딩하여 전송합니다.**

### 3.1 필수 전송 Key 명세
```json
{
  "carrotIndex": 1234,              // (선택) 패킷 인덱스 또는 카운터
  "nRoadLimitSpeed": 80,            // (필수) 현재 주행 중인 도로의 기본 제한 속도 (km/h)
  
  // --- 단일 안전운전 정보 (고정식 카메라, 이동식 카메라, 방지턱 등) ---
  "nSdiType": 1,                    // SDI 타입 코드
                                    //   0: 이벤트 없음 (평상시)
                                    //   1: 고정식 과속 카메라
                                    //   7: 이동식 단속 카메라
                                    //  22: 과속 방지턱
  "nSdiSpeedLimit": 80,             // 전방 단속 카메라의 제한 속도 (방지턱일 경우 0으로 처리해도 무방)
  "nSdiDist": 450,                  // 단속 카메라 또는 방지턱까지 남은 거리 (m)
  
  // --- 구간 단속 관련 (해당 구역 진입 시 포함) ---
  "nSdiBlockType": 2,               // 구간단속 상태
                                    //   1: 구간단속 시작 지점
                                    //   2: 구간단속 진행 중
                                    //   3: 구간단속 종료 지점
  "nSdiBlockSpeed": 80,             // 구간단속 구역의 규정 제한 속도
  "nSdiBlockDist": 1500             // 구간단속 종료 지점까지 남은 총 거리 (m)
}
```

## 4. 단방향 통신 시 핵심 작동 원리

1. **지속적인 데이터 푸시 (Heartbeat 역할)**
   - UDP 단방향 통신이므로 패킷 유실이 발생할 수 있습니다. 이를 보완하기 위해 앱은 **최소 1초에 2~5회 (2~5Hz)** 주기로 현재 남은 거리(`nSdiDist`)를 갱신하여 7706 포트로 계속 던져주어야 합니다. 
   - 이렇게 지속적으로 쏘기만 하면, 중간에 패킷이 한두 번 누락되더라도 오픈파일럿이 다음 0.2초 뒤의 패킷을 잡아내어 실시간 거리에 맞게 브레이크를 부드럽게 밟습니다.

2. **이벤트 인식 및 자동 감속 (APN 활성화)**
   - 앱이 던진 데이터 중 `nSdiDist`가 0보다 크고, 유의미한 `nSdiType` (1, 7, 22 등)이 들어있으면 오픈파일럿은 즉시 전방에 카메라나 방지턱이 있다고 인지합니다 (화면에 녹색 "APN" 켜짐).
   - 일방적으로 받은 이 숫자만 가지고도 오픈파일럿이 자체적으로 거리 대비 현재 차량 속도를 계산하여 속도를 줄입니다.

3. **이벤트 종료 및 가속 복귀 (초기화)**
   - 카메라나 방지턱을 지나치고 나면, 앱은 `nSdiType: 0`, `nSdiDist: 0`을 담아서 데이터를 쏩니다.
   - 이 0 값 데이터를 받은 오픈파일럿은 위험 구간이 끝났다고 판단하여 원래 운전자가 설정해둔 크루즈 속도로 다시 가속합니다.

4. **평상시 일반 주행 상태 전송**
   - 단속 카메라가 없는 평시 도로에서도 데이터를 쏘는 것을 멈추지 마세요.
   - `nSdiType: 0`, `nSdiDist: 0`인 상태로 `nRoadLimitSpeed` (현재 도로 제한속도)만 정확히 담아 지속적으로 던지면, 오픈파일럿이 화면에 현재 속도 제한을 인식하고 고속도로에서 속도를 자동으로 맞춰주는 HDA 기능 등을 원활히 수행합니다.
