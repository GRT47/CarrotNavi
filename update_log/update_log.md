# CommaNav v1.2.1 업데이트 내역 (Release Notes)

이번 버전에서는 구간단속 시 여유가속(마진)을 부드럽게 조절하는 기능과 함께 사용자 편의성을 높이기 위한 UI/UX 업데이트가 진행되었습니다.

## 1. 구간단속 여유가속(마진) 부드러운 조절 알고리즘 적용
* **평균 속도 기반 보상 가속 로직**:
  * 구간단속 중 현재 평균 속도가 제한 속도보다 1km/h 이상 낮을 경우, 부족한 속도에 비례하여 여유가속 마진을 부여해 목표 평균 속도에 도달하게 하는 알고리즘을 적용했습니다.
  * 차이가 클 때는 설정한 여유가속이 100% 반영되고, 차이가 줄어들수록 여유가속이 부드럽게(Proportional) 감소하여 단속 종점에서는 제한 속도에 안전하고 자연스럽게 수렴합니다.
* **오픈파일럿 TBT 패널 텍스트 동기화**:
  * 보상 가속이 실제로 진행 중일 때(즉, 여유가속 마진이 들어가고 있을 때)는 오픈파일럿 패널 텍스트가 `추가가속중`으로 변경되어 가속 개입 여부를 직관적으로 알 수 있게 했습니다.

## 2. 지도 화면 플로팅 패널 조절 기능 강화
* **원터치 및 롱프레스 연속 조절 (Auto-Repeat)**:
  * 지도 화면 우측 상단의 `+`, `-` 버튼을 한 번 탭하면 1단위로 바뀌고, 0.4초 이상 꾹 누르고 있으면 0.1초마다 값이 1씩 연속으로 변하도록 Auto-Repeat 기능을 추가하여 주행 중 안전하고 쾌적한 조작을 지원합니다.
* **구간단속 상세 정보 실시간 표시**:
  * 실제 구간단속 영역에 진입했을 때에 한해, 플로팅 조절 패널 하단에 `평균 속도`, `남은 거리`, `남은 시간` 세 가지 정보가 실시간으로 확장되어 나타나도록 UI를 개선했습니다.
  * 가독성을 위해 텍스트 크기를 키우고, 색상을 밝게 조절했으며, 시간 포맷 또한 초 단위(ex: 312초)에서 분:초 단위(ex: 5:12)로 변경했습니다.
  * 보상 가속이 진행 중일 때는 플로팅 패널의 상단 타이틀 역시 `구간단속`에서 `추가가속중`으로 동기화 변경됩니다.

## 3. 설정 내 거리 표시 단위 선택 옵션 추가
* **km 단위 변환 토글 기능**:
  * 앱 첫 화면(설정 화면)에 거리가 1000m 이상일 때 km 단위로 변환해 주는 체크박스 옵션을 추가했습니다.
  * 체크 시 1200m 대신 `1.2km`와 같이 간결하게 표시되며, 지도 좌측의 기본 안내 이벤트와 우측 구간단속 상세 정보 패널의 거리에 모두 일괄 적용됩니다.

# CommaNav v1.2.0 업데이트 내역 (Release Notes)

이번 버전에서는 오픈파일럿(Openpilot) 화면과의 상시 연동을 강화하고, 앱 내 환경 설정 및 정보 탐색 시인성을 극대화하기 위한 UI/UX 리팩토링이 집중 진행되었습니다.

## 1. 오픈파일럿 HUD 연동 개선 (안심주행 GPS 상시 노출)
* **실시간 GPS 위성 수신 정보 전송**:
  * 안드로이드 기본 GPS 상태 모니터링(`GnssStatus.Callback`)을 구현하여 실시간 위성 개수 및 신호 감도를 측정합니다.
  * 측정된 신호를 바탕으로 오픈파일럿 안내 정보(`szTBTMainText`) 영역에 실시간 GPS 정보(예: `안심주행 | GPS: GOOD(7)`)를 포함하여 송출하도록 연동을 고도화했습니다.
* **안심주행 패널 상시 노출 우회**:
  * 목적지를 설정하지 않은 단순 주행(안심주행) 상황에서도 오픈파일럿 HUD 화면에 GPS 상태 안내판이 상시 표시되도록 필수 조건 우회 로직을 적용했습니다.
  * 오픈파일럿 HUD 렌더링 필터링 통과를 위해 가상 TBT 데이터(`nTBTDist=9999`, `nTBTTurnType=51`) 및 가상 목적지 도착 데이터(`nGoPosDist=1`, `nGoPosTime=1`)를 UDP 페이로드에 더미로 주입하여 상시 노출을 구현했습니다.

---

## 2. 앱 UI 레이아웃 및 텍스트 구조 개선
* **세로 모드 연결 상태 카드 텍스트 쪼개짐 해결**:
  * 연결 상태 카드 우측 영역에서 버전 정보와 IP 정보가 한 줄로 배치되어 IP 주소(예: `0.0.0.0`)가 세로로 쪼개져 출력되던 레이아웃 버그를 정정했습니다.
  * 가로(Horizontal) 정렬에서 **세로(Vertical) 정렬**로 변경하여 가독성을 한층 더 확보했습니다.
* **설정 진입 명칭 직관성 강화**:
  * 지도 화면 우측 상단의 기존 `"Key 수정"` 버튼 텍스트를 기능에 맞는 직관적인 **`"설정"`**으로 변경했습니다.
* **브랜드명 통일화**:
  * 설정 화면의 메인 타이틀 문구를 기존 `"CarrotNavi 설정"`에서 **`"CommaNav 설정"`**으로 수정하여 브랜딩 통일성을 높였습니다.
* **설정 화면 내 앱 버전 표시**:
  * 사용자가 현재 구동 중인 앱의 버전 정보를 손쉽게 인지할 수 있도록, Android 패키지 관리자로부터 실시간 버전을 쿼리하여 설정 화면 하단에 표시해 주는 기능을 추가했습니다.

## 3. 안정화 및 품질 제어
* **가로 모드 속도 제한 표시 통일**:
  * 가로(Landscape) 모드 전환 시 도로 제한속도 표지판의 스타일이 빨간 동그라미(유럽식)로 표시되던 실수를 교정하여, 세로 모드와 동일한 **미국식 사각형(SPEED LIMIT)** 표지판 스타일로 레이아웃 디자인을 통일했습니다.
* **화면 전환 크래시 방지**:
  * 세로/가로 모드 전환 및 액티비티 생명주기 이동 시 데이터 바인딩 뷰 참조에서 발생할 수 있는 null 참조 예외에 대한 방어 로직을 적용했습니다.
* **버전 관리 및 배포**:
  * 앱 버전 명칭을 공식 빌드 버전 **`v1.2.0`** (Version Code `9`)으로 승격하고 배포용 APK를 성공적으로 빌드해 두었습니다.
